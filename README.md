# منصة السهم العلمي للاختبارات الذكية وتقويم الأداء — الإصدار 3.5

منظومة واحدة: الدفتر الجانبي ومنصة الاختبارات صارا نظامًا واحدًا على قاعدة بيانات واحدة (Supabase).

| الصفحة | لمن | ماذا فيها |
|---|---|---|
| `index.html` | الطلبة | الموقع، دخول الطالب، صفحته بأقسامها، الاختبار المحمي، النتيجة |
| `teacher.html` | المعلّم | المنظومة كاملة (انظر الأقسام أدناه) |
| `book.html` | — | تحويل تلقائي إلى `teacher.html` (الدفتر القديم انتهى) |

## أقسام منظومة المعلّم
- **لوحة القيادة**: مؤشرات الشعبة، ما يحتاج انتباهك الآن، الطلبة المحتاجون دعمًا، خريطة الإتقان.
- **الحصة الآن**: الحضور والغياب بلمسة، الرصد اليومي لعدة طلبة دفعة واحدة، طالب عشوائي.
- **رصد النتاجات**: جدول الطالب × النتاج، بالنقر أو بلوحة المفاتيح (1–4)، وتعبئة عمود كامل.
- **العلامات**: الاختبار الأول والنهائي، والتقويم الثاني يُحسب تلقائيًّا، والمجموع والتقدير.
- **بنك الأسئلة**: ٩٨٠ سؤالًا من الكتاب (٧٠ لكل درس × ١٤ درسًا)، مصنّفة بالوحدة والدرس والنتاج ومستوى بلوم والصعوبة، على نمط أسئلة الوزارة.
- **الاختبارات والكويزات**: مرقّمة تلقائيًّا (الكويز ١، ٢… الاختبار ١، ٢…)، سحب ذكي، حماية من الغش، تحليل، اعتماد في السجلات.
- **أوراق العمل** (جديد): من البنك، ورقية تُطبع لكل طالب أو إلكترونية، مرقّمة (ورقة العمل ١، ٢…)، رصد سريع بالنقر أو بالحروف، وتُرصد في النتاجات بأداة «ورقة العمل».
- **التعليم المتمايز** (جديد): كل أداة عدا الاختبار الكتابي تأخذ لكل طالب نموذجًا حسب آخر معدل له (◆ دعم، ● أساسي، ▲ إثراء) مع علامة موزونة عادلة، ومجموعات متمايزة داخل الحصة.
- **الطلبة والشعب**: إضافة/تعديل/نقل/حذف/أرشفة، بيانات الدخول، بطاقات الدخول، ملف الطالب وتقريره.
- **نماذج الرصد الورقية** (جديد): ورقة الرصد اليومي للحصة (ليوم أو لشهر/فترة، صفحة لكل يوم دوام، كل الطلاب في صفحة واحدة عموديًا، أعمدة قابلة للاختيار، اسم مختصر، عمودي أو أفقي)، وورقة رصد النتاجات للملاحظة الصفية والأسئلة الشفوية — من «الحصة الآن» و«رصد النتاجات» و«السجلات».
- **السجلات والطباعة**: ثمانية سجلات رسمية بفلاتر، وطباعة A4 إجبارية (عمودي/أفقي)، وExcel منسّق.
- **الإعدادات**: بيانات المعلّم، الرقم الوطني، تقسيمة العلامة وقاعدة الاحتساب، الإشعارات، نسخة احتياطية.

## صفحة الطالب
- **نتائجي**: علاماته (الأول، الثاني من النتاجات، النهائي، المجموع والتقدير) مع تفصيل حساب التقويم الثاني، وكل الكويزات والاختبارات وأوراق العمل، وسجل أدوات التقويم مرقّمًا — نفس ما عند المعلم.
- **الواجهة**: بطاقات العلامات (الأول من 30، الثاني من 30، النهائي من 40، المجموع من 100) وتوصيات ذكية مفصّلة مع «عرض كل التوصيات».
- **سلوكي وحضوري**: بطاقات إحصائية (حضور، غياب، تأخر، مشاركة، سلوك، ملاحظات، صافي النقاط) وتفاصيل كل بطاقة عند النقر.

## النشر على GitHub
1. افتح المستودع على github.com ← **Add file ← Upload files**.
2. اسحب **كل** محتويات هذا المجلد (بما فيها مجلد `assets`) واستبدل القديم، ثم **Commit changes**.
3. احذف من مجلد `assets` في المستودع الملفات القديمة إن وُجدت: `app.css` و`teacher.js` و`teacher-bridge.css`.
4. بعد دقيقتين افتح الموقع؛ يجب أن ترى «الإصدار 3.5» في صفحة دخول المعلّم.

## الإشعارات بالبريد
- تعمل تلقائيًّا كل ١٥ دقيقة بعد إغلاق أي اختبار، بشرط حفظ مفتاح **Resend** في Supabase:
  Supabase ← Edge Functions ← Secrets ← Add ← الاسم `RESEND_API_KEY` والقيمة المفتاح الذي يبدأ بـ `re_`.
