# منصة السهم — الاختبارات + الدفتر الجانبي

موقع واحد على GitHub Pages، وقاعدة بيانات واحدة على Supabase (مشروع «daftar-janibi»).

| الصفحة | لمن | ماذا فيها |
|---|---|---|
| `index.html` | الطلبة | الدخول بالرقم الوطني وتاريخ الميلاد، الاختبارات المفتوحة، الحل، النتيجة |
| `teacher.html` | المعلم | الأسئلة، الاختبارات، النتائج والتحليل، بيانات دخول الطلبة، التنبيهات |
| `book.html` | المعلم | الدفتر الجانبي نفسه (يُحمَّل من قاعدة البيانات) |

## النشر على GitHub (مرة واحدة)
1. من github.com اضغط **New repository**، سمِّه مثلًا `sahm`، اختر **Public**، ثم **Create repository**.
2. اضغط **uploading an existing file**، واسحب كل محتويات هذا المجلد (بما فيها مجلد `assets`)، ثم **Commit changes**.
3. من **Settings ← Pages**: اختر **Deploy from a branch**، والفرع **main** والمجلد **/(root)**، ثم **Save**.
4. بعد دقيقة أو دقيقتين يصبح الموقع على: `https://اسم-حسابك.github.io/sahm/`

- رابط الطلبة: `https://اسم-حسابك.github.io/sahm/`
- رابط المعلم: `https://اسم-حسابك.github.io/sahm/teacher.html`

## التحديث لاحقًا
ارفع الملف المعدَّل بالطريقة نفسها (Add file ← Upload files) فيستبدل القديم، ويتحدّث الموقع خلال دقيقة.

## ملاحظات
- المفتاح في `assets/config.js` مفتاح عام مخصّص للمتصفح؛ الحماية كلها في قاعدة البيانات (الطالب لا يقرأ أي جدول مباشرة، ولا يصله مفتاح الإجابة).
- توقيت الاختبارات بتوقيت الأردن.
